# Ventas aparcadas

A veces un cliente se va a buscar su cartera, o a mirar otra talla, y llega otro. En lugar de borrar el carrito, **aparca** la venta.

## Aparcar una venta

1. Con el carrito que quieres dejar, pulsa **Hold Cart** (retener venta).
2. Escribe una **nota** para reconocerla («chica del abrigo azul»).
3. El carrito se guarda y se abre uno nuevo, vacío, para el siguiente cliente.

> No se puede aparcar un carrito vacío.

## Recuperarla

Abre la lista de ventas aparcadas (**Hold Carts**), busca la que quieras y pulsa sobre ella. Vuelve a abrirse con sus productos y su nota.

Si no hay ninguna aparcada, la lista dice que no hay pedidos retenidos.

## Qué conviene saber

- Las ventas aparcadas **no descuentan stock** hasta que se cobran.
- Si cierras la caja de efectivo o terminas el turno, **no dejes ventas aparcadas**: cóbralas o descártalas.
- Si cambias de dispositivo, comprueba que la venta aparcada se ve desde el nuevo.
